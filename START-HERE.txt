RIVAL WEBSITE

1. Extract the entire ZIP first. Do not open the pages from inside the ZIP.
2. Open index.html with a modern web browser.
3. Keep the six HTML files, style.css and images folder together.

No installation or web server is needed. Local pages and images work without internet; external game website links require internet.

Designed for modern Chrome, Edge, Firefox and Safari on Windows, macOS and Linux. Older browsers may display the layout differently.

The site uses HTML and CSS only. Results are examples, and registrations and accounts are not implemented.

START-HERE.txt is optional and can be deleted.
